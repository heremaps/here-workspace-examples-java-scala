    Creates a StreamingPathMatcher that applies road-access and edge-access restrictions.

    This is an experimental API. It may be removed or changed from one version to the next.

    Creates a StreamingPathMatcher that applies road-access and edge-access restrictions.

    O

    The observation type.

    V

    The vertex type.

    E

    The edge type.

    LS

    The line string type for vertex geometries.

    proximitySearch

    Performs spatial searches to find candidate vertices near observations.

    graph

    The road network graph.

    geometry

    Maps each vertex to its geometry (line string).

    length

    Maps each vertex to its length in meters.

    roadAccess

    Vertex-level road accessibility; ranges with value true are accessible.

    accessRestriction

    Edge-level restrictions; true blocks the edge.

    geoProjection

    Optional custom geo-projection; defaults to sinusoidal.

    codec

    Implicit VirtualIndexCodec required to patch virtual indices. For in-memory graphs, import com.here.platform.location.inmemory.graph.patch.scaladsl.Implicits._.

    returns

    A StreamingPathMatcher configured with both road and edge access restrictions.
