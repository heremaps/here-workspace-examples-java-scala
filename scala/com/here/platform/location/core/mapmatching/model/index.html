  2.  final class HMMForwardState[O, V] extends AnyRef

    Minimal forward state required to continue the HMM algorithm from the last processed observation.

    This is an experimental API. It may be removed or changed from one version to the next.

    Minimal forward state required to continue the HMM algorithm from the last processed observation.

    Used as the hand-off payload for distributed processing: after node N finishes a batch, it extracts this context from HMMMatcherState (as an Option) and transfers it to node N+1, which resumes matching without requiring the full observation history.

    candidates and costs are index-aligned, must have the same length, and must be non-empty (at minimum one MatchCandidate.unmatched sentinel when no road candidates exist).
